# 🛡️ Hybrid Network Intrusion Detection System (HIDS)

A Hybrid Intrusion Detection System that combines **Rule-Based Signature Detection** with **Isolation Forest** to detect both known and unknown cyber threats. The project also integrates **SHAP** for explainable AI and **Streamlit** for interactive visualization.

## 🚀 Tech Stack
- Python
- Pandas & NumPy
- Scikit-learn
- Isolation Forest
- SHAP
- Streamlit

## 📂 Dataset
- CICIDS2017
- Benign Traffic
- PortScan
- Web Attacks

## 🏗️ Project Architecture

Network Traffic
↓
Rule-Based Signature Detection
↓
Isolation Forest
↓
SHAP Explainability
↓
Streamlit Dashboard
